# Planning provenance

This repository setup codifies the accepted decisions from the project conversations **Initial Guild Site Discussion** and **MVP Feature Planning**, reviewed on 6 October 2026. The user accepted the proposed MVP, architecture direction, four milestones, and GitHub-native tracking structure.

Accepted decisions include Next.js/React/TypeScript, Go, PostgreSQL, Docker, GitHub, a modular monolith, domain-oriented code, Discord OAuth linked to internal users, internal RBAC, versioned REST, application state/history/private comments, recruitment controls, and officer notifications.

The documentation adds implementation guidance and concrete acceptance criteria to make that plan actionable. It explicitly labels unresolved transition rules, membership policy, validation bounds, notification durability, tooling, deployment choices, and dates. Example guild names, character values, or recruitment priorities from discussion are not production content.

The documentation and tracker setup are deliverables of this task. Building the working product is future issue work; folder scaffolding and accepted ADRs do not imply completed features.
