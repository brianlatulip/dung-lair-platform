# MVP release checklist

- [ ] M0–M3 acceptance criteria and MVP-01 through MVP-12 have evidence.
- [ ] Public copy, branding, invite link, and recruitment needs are approved.
- [ ] OAuth callback, repeat login, expiry, logout and CSRF controls are exercised.
- [ ] Internal Admin bootstrap and role revocation work without privilege escalation.
- [ ] Applicant submission and status work on mobile and desktop.
- [ ] Cross-user access and private-note leakage tests pass.
- [ ] Officer review transitions, conflicts, comments and history work.
- [ ] Discord failures/retries/restart recovery have been exercised.
- [ ] Recruitment edits persist and appear publicly.
- [ ] Loading, empty, validation and service-failure states are usable.
- [ ] Images/artifacts, production secrets, TLS and database network boundaries are configured.
- [ ] Migrations, deployment smoke test, and isolated backup restore pass.
- [ ] Logs and operational recovery are documented.
- [ ] Open product decisions affecting release are resolved.
- [ ] A real end-to-end guild workflow is demonstrated and remaining limitations recorded.

This checklist is intentionally unchecked at repository setup. Planning completion is not product completion.
